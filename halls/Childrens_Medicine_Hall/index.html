This portal is local-first. Saved notes, quiz scores, favorites, logs, and report notes remain in this browser unless the family exports or shares them. Use this vault before switching computers or clearing browser storage.

GitHub Upload Checklist

  1. Do not commit a family vault export or personal medicine log to GitHub.
  2. Upload only the standalone HTML portal, not private JSON backups.
  3. Open the uploaded GitHub Pages URL and test: tabs, filters, dossier close, quiz module selector, export/import, print report, and mobile layout.
  4. Review source links quarterly because public-health guidance can change.
